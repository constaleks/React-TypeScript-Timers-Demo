# React TypeScript Timers Demo

A small study/pet project created to practice **TypeScript with React**.

The app allows users to create and manage multiple timers. Each timer has a name and a duration in seconds.

The functionality is intentionally kept simple, with the main focus being on applying TypeScript concepts in a React application.

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Vite

## Purpose

This project is focused on learning and practicing:

- TypeScript types and interfaces
- Typing React components and props
- Typing state with `useState`
- Typing event handlers
- Working with arrays and objects in TypeScript
- TypeScript with React component composition
- Managing timer-related state and logic

The application itself is intentionally small since the primary goal is to gain practical experience using TypeScript with React.
